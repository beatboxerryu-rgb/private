# ファイル運用ルール

## 正の置き場所

共有ドライブ AI作業_システム部 / 10_案件 / B社_GPO-Intune_2026 配下。
参照許可は都度明示される。指示がない限り読み取らない。

## フォルダの使い分け

| フォルダ | 用途 |
| ---- | ---- |
| 10_working | 生成物の新規作成先。既存ファイルの上書き・移動・削除はしない |
| 20_fixed | 前提とする確定版はここのもののみ |
| 30_review | 指摘一覧の新規作成先 |

- 参照除外フォルダの取り扱いはプロジェクト指示の原文を正とする（本ノートには転記しない）

## ファイル命名

- 通常の成果物: {工程番号}_{成果物名}_v{版数}_{YYYYMMDD}
- 指摘一覧: R{連番}_{対象ファイル名}_指摘_{日付}

## 運用ルール

- 資料に言及するときは必ずファイル名と版数を明記する
- コメントや提案モードは読み取れないため、レビューは本文テキストで行う
- 出力ファイルの文字コード等は [[06_出力書式規約]] に従う
