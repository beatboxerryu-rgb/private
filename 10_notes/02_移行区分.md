# 移行区分（A〜F）

GPO 設定を扱うときは必ずこの区分を付ける。本案件の区分体系はこれのみ。
他資料で別体系が出た場合は「旧区分」と明示して読み替える。

| 区分 | 意味 | 補足 |
| ---- | ---- | ---- |
| A | 設定カタログ（SC）で同等の設定がある | |
| B | 管理用テンプレート（ADMX）で対応可能 | |
| C | Intune の別機能で代替 | Endpoint security / WUfB / Autopilot / アプリ / 証明書 / Wi-Fi・VPN |
| D | PowerShell または修復スクリプトで代替 | |
| E | Intune では実現できない | 運用または別製品で吸収。判断理由を必ず併記 |
| F | 移行不要 | 廃止・形骸化・重複。判断理由を必ず併記。候補は積極的に挙げる |

## 運用メモ

- E と F は判断理由の併記が必須
- F の候補は積極的に挙げること（ゴールは「クライアントに適用される GPO を 0 本」）
- GPO 棚卸し表の列構成は [[04_採番と書式]] を参照
