# 00_伏字プレースホルダ規約（ナレッジ転記）

プロジェクトナレッジ「00_伏字プレースホルダ規約」の転記。正はプロジェクトナレッジ側。

## 形式

＜種別プレフィックス-連番＞。全角山括弧、連番はゼロ埋め 2 桁。GPO のみ 3 桁。

## 種別一覧（この一覧に限定。新種別が必要なら追加を提案し、勝手に増やさない）

| プレフィックス | 種別 |
| ---- | ---- |
| SRV | サーバー |
| DOM | ドメイン・フォレスト |
| TEN | M365 テナント |
| OU | 組織単位 |
| GPO | GPO 名 |
| SG | セキュリティグループ |
| USR | ユーザー・UPN・サービスアカウント |
| SITE | 拠点 |
| NET | サブネット |
| IP | 個別 IP |
| SHR | 共有パス (UNC) |
| PRN | プリンター |
| DRV | ドライブ文字とマップ先 |
| PATH | ローカルパス |
| URL | 社内 URL |
| CERT | 証明書テンプレート・CA |

## 規則

- 既に OU-01 形式で伏字化済みの OU は ＜OU-01＞ に統一（同一 ID として扱う）
- プレースホルダに役割名や実名の断片を含めない（＜FileSRV-01＞ のようにしない）
- 原則は全角山括弧。ASCII 必須の箇所（ファイル名、スクリプト内リテラル、CSV）に限り {{SRV-01}} を使用してよい。使用時は成果物の凡例に明記する
- 実値との対応マスターは自社管理領域で管理し、このプロジェクトには投入しない
- 既存 ID の再利用はしない。廃止時も欠番のまま残す
- 顧客名は B社、ドメインは corp.example、ユーザーは user01@ 形式、グローバル IP は x.x.x.x
