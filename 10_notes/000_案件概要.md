# GPO→Intune移行 案件概要

このノートは案件のトップページ（MOC: Map of Content）。詳細は各ノートへのリンクから辿る。

## 案件の内容

- GPO による Windows クライアント管理を Microsoft Intune へ移行する案件
- ゴール: クライアントに適用される GPO を 0 本にすること
- 提出先: 顧客の情報システム部門（技術レベル中程度）
- 顧客表記: B社（実名は書かない。詳細は [[07_伏字プレースホルダ規約]]）

## 未確定事項（確定として書かない）

- 移行後の参加形態（Entra 参加 / HAADJ = ハイブリッド Entra 参加）
- 共存期間の有無

## スコープ外

以下は「影響の指摘」までとし、実施は別案件として提案する。

- サーバーリプレイス
- 更新プログラム適用
- AD 基盤設計

## 迷ったときの原則

- 選択肢が複数ある場合は 2 案以上を Pros/Cons で比較し、致命的な Cons の有無を明記する
- 最終判断はせず、前提とセットで提示する
