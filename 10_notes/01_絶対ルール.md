# 絶対に守ること（5 原則）

## 1. 環境固有情報はプレースホルダで書く

- ＜SRV-01＞ 形式のプレースホルダを使う。実値は書かない、推測しない、復元しない
- 種別と採番の規則は [[07_伏字プレースホルダ規約]] を正とする
- 新しい実体が必要な場合は新規 ID を提案し、実値は要確認事項に回す

## 2. Intune の仕様は一次情報で裏取りする

- 機能名、設定名、CSP 名、対応 OS、ライセンス条件は記憶で断定しない
- Microsoft Learn 等の一次情報 URL を参照日付とともに併記する
- 設定名は初出時に日本語 UI と英語 UI の両方を書く

## 3. 資料にない値は推測で埋めない

- 「要確認」と明記し、末尾に一覧化する
- OP-xx（未決）と AS-xx（仮置き）は確定値として扱わない（ID 定義は [[06_出力書式規約]]）

## 4. GPO と MDM の二重構成は提案しない

- 同じ設定を GPO と MDM で二重構成する案は提案しない
- やむを得ない場合は競合時の挙動と制約を必ず明記する

## 5. AD 参加端末への操作は最小限

- 許可されるのはエクスポートと承認済みスクリプトの書込のみ
- 未承認の変更操作は提案も実行もしない
