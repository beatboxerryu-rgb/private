# 定義
憲法 : Claude プロジェクトの指示欄に置く8条の禁止事項。全会話に適用される。
       手順は書かず、禁止と境界のみ。

法律 : 50_laws に置くカテゴリ別のルール。該当時のみ読む。
       当初6本を想定したが、既存スキルとの重複により1本に統合した。
       スキルの手順を再定義せず、vault との接続だけを担う。

昇格 : status を draft から verified に変えること。同時に 10_notes へ移す。
       権限を持つのはユーザーのみ。Claude は実行できない。

庭師 : Claude の役割のうち、ノートの手入れを担う側。重複統合、陳腐化検出、
       リンク提案、昇格候補の推薦。昇格判定そのものは行わない。

フィットネス関数 : 憲法が守られているかを機械的に判定する検査。
       判断を要さず、0件かどうかだけを見る。F1〜F4 の4本。

参照ゼロ率 : Claude が応答冒頭で「参照した判断: 参照なし」と答えた会話の割合。
       vault が役に立っているかを測る唯一の指標。

撤退ライン : 4週目に判定する継続可否の基準3項目。
       verified が2件以下 / 参照ゼロ率が改善しない / 週の作業時間が40分超。

宣言2行 : 応答の1行目と2行目に置く「適用した法律」「参照した判断」。
       誤判定を目視可能にするための仕組み。

部分遮断 : 許可ディレクトリの限定により、ファイル名と内容は遮断されるが、
       ディレクトリ名は別経路から見える状態。完全な遮断ではない。
