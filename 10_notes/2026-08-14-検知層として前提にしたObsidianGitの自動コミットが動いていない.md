# 結論
検知層として前提にした Obsidian Git の5分間隔コミットが動作していない。
リポジトリの全履歴は3コミットのみで、約22時間分の変更が1コミットに
圧縮されている。F1 は今後も判別不能が続く。

# 昇格条件
Obsidian Git の自動コミットが動作し、1日あたり複数コミットが記録されたら verified。

# 事実
事実: リポジトリの全履歴は3コミット（8/13 11:28、8/14 09:51、8/14 11:16）（出典: 庭師による実機確認、2026-08-14）
事実: F1 で検出された唯一のコミットは verified 7件を含むファイル群の新規追加であり、draft から verified への変更差分ではない（出典: 庭師による実機確認、2026-08-14）
事実: 昇格操作が初回バックアップより前に完了していたため、状態遷移が Git 履歴に存在しない（出典: 庭師による実機確認、2026-08-14）

# 影響
判断: 決定7（失敗記録の優先昇格）が前提とした検知層が機能していない
判断: Claude が 00_inbox のノートを上書きしても、現状では検出できない
判断: 昇格前のノートは、検知も遮断もされていない状態にある

# 原因の候補（未確定）
判断: Obsidian が起動していない時間帯がある。プラグインは Obsidian が
      動作していないとコミットしない
判断: interval の設定値が保存されていない
判断: プラグインが無効、または認証エラーで停止している

# 成立しない場合の選択肢
判断: Claude の書き込み直後にユーザーが手動でコミットする
判断: 検知層を諦め、憲法3条のルールによる約束のみとする

# F2 の書式固定を採用
事実: 事実行27行中26行が F2 でヒットしたが、出典の記載自体がないノートは
      0件だった。出典がブロック末尾にまとめて書かれているか、行の折り返しで
      継続行に落ちていたことが原因（出典: 庭師による実機確認、2026-08-14）
判断: 除外リストを増やす方向は行き止まり。庭師の提案を採用する
判断: 事実行は1行完結とし、行末に（出典: URLまたは一次経験の別、YYYY-MM-DD）を
      必ず置く。折り返しと、複数事実へのまとめ出典を禁止する
判断: 検査は「事実で始まり、出典を含まない行」のみになり、除外リストが不要になる
判断: 副作用として1行が長くなり、可読性が落ちる

# F4 の除外判断
判断: 同一ノート内の表参照は自己完結性を損なわないため除外する。
      ただし機械的に区別できないため、今後も目視除外が必要

# 未検証
Obsidian Git が動作していない原因。ステータスバーと設定値の確認が必要。
