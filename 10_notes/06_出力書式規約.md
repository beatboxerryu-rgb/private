# 00_出力書式規約（ナレッジ転記）

プロジェクトナレッジ「00_出力書式規約」の転記。正はプロジェクトナレッジ側。

## ファイル形式

- 生成するテキストは BOM 付き UTF-8 + CRLF
- ZIP 内のファイル名は ASCII

## 略語

| 略語 | 意味 |
| ---- | ---- |
| GPO | グループポリシーオブジェクト |
| SC | 設定カタログ |
| ADMX | 管理用テンプレート |
| Co-management | 共同管理 |
| HAADJ | ハイブリッド Entra 参加 |

## 自社略語

| 略語 | 意味 |
| ---- | ---- |
| BD | 基本設計 |
| DD | 詳細設計 |
| 構築手順 | 構築手順書 |
| 成績書 | 試験成績書 |

## プロジェクト固有 ID

| ID | 意味 |
| ---- | ---- |
| OP-xx | 未決の判断事項 |
| AS-xx | 仮置き前提 |
| S-xx | 調査依頼票 |
| R-xx | リスク |
