# 結論
一目で読ませる見出しは13文字が安全圏だが、理解の正確さは15文字前後まで落ちない。「9〜13文字が認識の限界」は一次的根拠のない通説である。

# 昇格条件
自分の資料で13文字版と15文字版を第三者に2秒提示し、理解度の差を実測できたとき。

# 根拠
事実: Yahoo!ニュース トピックスの見出しは11文字 → 2001年に最大13.5文字 → 2021年4月に14.5文字 → 2022年1月に15.5文字と拡大された（https://www.kobe-np.co.jp/rentoku/omoshiro/202212/0015902584.shtml、2026-08-14確認）
事実: ヤフーの検証では13.5〜16.5文字の6パターンで認識速度はすべて2秒以下、差はわずか。正確な理解は15文字以上で高評価だった（https://www.itmedia.co.jp/business/articles/2201/27/news194.html、2026-08-14確認）
事実: 公用文作成の考え方（文化審議会建議 令和4年1月7日）は、一文を短く、一文一義、三項目以上は箇条書き、受身をむやみに使わない、二重否定を避ける、専門用語は言い換えるを示す（https://www.bunka.go.jp/seisaku/bunkashingikai/kokugo/hokoku/pdf/93651301_01.pdf、2026-08-14確認）
事実: やさしい日本語ガイドライン（2020年8月、出入国在留管理庁・文化庁）は、一文一義、あいまい表現の抑制、敬語は丁寧語のみ、西暦表記、午前午後の明記を示す（https://www.bunka.go.jp/seisaku/kokugo_nihongo/kyoiku/pdf/92484001_01.pdf、2026-08-14確認）
判断: 13文字説はヤフトピの旧ルールが一人歩きした可能性が高い。字数制限は認知限界ではなく媒体の表示幅の制約である。

# 反証
表示幅が狭い媒体（バナー、モバイル通知、ボタン）では15文字が折り返され、13文字説が実質的に正しくなる。媒体の表示幅を確認せずに15文字を採用すると崩れる。

# 未検証
9文字という下限値の出所。日本語以外の言語での同種の検証。フォントサイズや書体が認識速度に与える影響。
