# 結論
憲法をプロジェクト指示に置く設計は、実務プロジェクト内の会話にしか
効かない。プロジェクト外では宣言もノート形式も守られず、
Filesystem 経由の書き込みだけは技術的に可能な状態になる。

# 昇格条件
2週間運用し、プロジェクト外で判断が生まれた回数を数えたら verified。

# 前提
事実: プロジェクト指示は当該プロジェクト内の会話にのみ適用され、
      カスタム指示は全会話に適用される
      https://global-axis.jp/blog/use_claude_projects/ (2026-08-07)
判断: Filesystem コネクターはアカウント単位の設定のため、
      プロジェクト外でも 00_inbox への書き込みは可能

# 対処案
判断: 迷ったらプロジェクト内で始める、を既定にする。
      調べ物のつもりが判断になる場合があるため
判断: プロジェクト外で判断が出たら、内容を実務プロジェクトに
      持ち込んで書かせる

# 代替案（未採用）
判断: 憲法をカスタム指示に置けば全会話に効き、この穴は消える。
      ただし vault と無関係な会話でも宣言2行が出るため、
      プロジェクト外の会話の割合次第で判断が変わる

# 未検証
プロジェクト外の会話がどの程度の割合を占めるか。
2週間の実測が必要。
